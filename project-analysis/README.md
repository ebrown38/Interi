  editor, asset import, animation, navigation, localization, HUD). Physics (Jolt) and RFG-style

  benchmarks, samples, testing, tools), HLSL 19 `.hlsl` + 7 `.hlsli`, Python 7 files (`tools/`),

- **Build system:** CMake 3.29+ with presets (`linux-clang-{debug,release,asan,tsan,coverage,tidy,profile}`,
  `windows-msvc-{debug,release,profile}`), Ninja, shared engine libraries by default.
- **Dependency manager:** vcpkg (vendored submodule `external/vcpkg`, manifest mode, overlay port `cmake/ports/ufbx`).
  Dependencies: benchmark, cgltf, directx-dxc (host), gtest, imgui (docking), manifold, meshoptimizer,
  miniaudio, nlohmann-json, recastnavigation, sdl3, spirv-reflect, stb, tinyobjloader, tracy, ufbx,
  volk, vulkan-headers, vulkan-memory-allocator, xxhash.
- **Platforms claimed:** Linux (Clang 22) and Windows (MSVC); PS5/Xbox Series backends in private repos;
  CPU baseline x86-64-v3.
- **Game/engine signals:** `engine/{render,rhi,rhi_vulkan,ecs,jobs,audio,scene,game,...}`, SDL3, Vulkan,
  Dear ImGui, Tracy, HLSL shaders (`engine/*/shaders`), README describing a game engine.
- **UI tech:** Dear ImGui editor (`engine/editor_ui`, `tools/editor`), in-game HUD/menu system (`engine/hud`).
- **Tests:** GoogleTest/GoogleMock via CTest (labels unit, stress, integration, golden, benchmark,
  license, pending), Google Benchmark, pytest-style tests under `tools/*/tests`, libFuzzer harness.
- **CI:** GitHub Actions (`.github/workflows/ci.yml`): format/SPDX, Linux preset matrix, Windows MSVC
  matrix, coverage, ASan/TSan.
- **License:** MIT (`LICENSE`), SPDX headers enforced; license allowlist in `tools/license_check/license_policy.json`.
- **Remote:** `git@github.com:ebrown38/Interi.git` (public forge).
